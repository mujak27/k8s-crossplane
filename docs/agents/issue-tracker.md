# Issue tracker: GitHub

Issues and specs live in mujak27/k8s-crossplane on GitHub.
Use the gh CLI, scoped explicitly with --repo mujak27/k8s-crossplane.

Read issue bodies, comments, and labels before acting.
Check existing issues before creating duplicates.
Apply labels from `docs/agents/triage-labels.md`.
Publish one issue per approved ticket. Publication does not authorize
implementation.

Record blocking edges using GitHub's native issue dependencies.
If unavailable, include explicit blocking issue links in each ticket
and report the limitation.

PRs as a request surface: no.
